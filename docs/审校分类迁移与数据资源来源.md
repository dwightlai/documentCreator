# 审校分类迁移与数据资源来源

## 迁移范围

数据库迁移 `V43__review_business_categories.sql` 将已有审校规则、历史问题和审校方案的分类转换为六个业务类别。`V44__review_fact_rule_alignment.sql` 再把已有的「行文理由与依据」和「专名、日期、数字和引文」规则精确归入「政策法规与事实依据」。规则代码、问题处理记录和方案 ID 保持不变。词库类型与词条标签描述数据对象，不改成审校问题类别。迁移由 Flyway 在应用启动时执行一次；执行前应按部署要求备份数据库。

审校方案原先以 L1—L7 保存检查范围。迁移把这些值转换为业务类别，运行时再选择所需检测器。同一方案同时含 L1 和 L2 时会得到重复的「语言文字」值，服务读取时去重。旧的历史问题只变更分类标签，不重新判定原文或改写处理结论。

## 本次数据包

`official-review-pack.json` 当前版本为 `2026.11.04-1`。数据包包含 56 条可执行文本规则和 7 部被规则引用的词库，合计 1493 条待核对词形。其中 `gf1001-2001-variants.json` 为 338 组、362 条。原包的 60 条纯人工核验规则及 6 部参考词库不再装载到规则中心；未被用户编辑的旧预置记录由 `V45__remove_reference_only_review_pack_data.sql` 清理。生产验收条件和未覆盖范围见[生产级审校数据建设与验收](生产级审校数据建设与验收.md)。

词库只有在生效规则显式引用时才参与自动匹配。异形词规则只提出推荐写法供人核对，不自动替换。其他公开资料仍可保留在知识库作依据检索，不计入自动审校规则数。

## 更新要求

每次更新先核验来源是否仍公开、标准或文件是否现行，再保留新旧版本、条款差异和核验记录。涉及机构名称、现任职务、政策时效的资料应标记发布日期，并在离线更新包中携带原文；无法确认时只给出人工核验提示。新增自动规则需经过样例和反例测试、审核、发布后生效。
