# 政文智枢 用户使用手册

适用版本：V1.6（2026-10-23）

政文智枢是面向政务机关的智能公文写作与审校平台，覆盖“材料准备 → 写作规划 → 提纲 → 正文 → 审校 → 套红定稿 → 提交”的完整流程。本手册面向公文起草人员、核稿人员和系统管理员。

> **使用原则**：平台中所有 AI 生成、改写、推荐的内容都必须经人工复核后使用。平台会自动标识 AI 参与的段落，并在导出时保留来源信息。

## 1. 使用前须知

### 1.1 访问与登录

- 使用单位提供的平台地址访问，推荐使用 Chrome、Edge 或国产浏览器的最新版本。
- 正式环境通过单位统一身份认证登录，权限（普通用户、核稿人员、管理员）由统一身份中的角色决定。
- 页面右上角显示“内网安全环境”和所在部门。

### 1.2 密级与数据边界

- 每项写作任务须选择密级（公开、内部、秘密、机密）。
- 涉密文稿禁止调用外部模型，由平台模型网关统一拒绝；材料、知识检索均按数据权限过滤，只能看到和引用有权限的内容。

### 1.3 角色说明

| 角色 | 主要工作 |
|---|---|
| 起草人员 | 创建写作任务、准备材料、生成与编辑正文、套红定稿、发起审校、提交 |
| 核稿人员 | 批注、提出修订、接受或拒绝修订、处置审校问题、确认提交 |
| 管理员 | 维护审校规则与词库、输出模板、模型路由、提示词、文种配置和提交门禁，查看审计台账 |

## 3. 快速上手：完成一篇公文

以“关于申请专项资金的请示”为例：

1. **新建任务**：进入“智能写作”，点击写作任务旁的“＋”，填写任务名称、文种、密级、写作主题、写作目的和字数范围，点击“创建任务”。
2. **写作规划**（可选）：在任务页点击“生成写作思路”，确认后点击“确认并锁定本版思路”；可用“标题候选”挑选标题。
3. **进入工作区**：点击“进入材料 / 提纲 / 正文工作区”。
4. **加入材料**：在“01 材料依据”栏点击“＋”，上传依据文件或录入经核准的材料片段，然后点击“固化材料权限快照”。
5. **生成并确认提纲**：在“02 写作提纲”栏点击“生成”，调整章节后点击“结构检查”和“确认提纲”。
6. **生成正文**：在提纲中选择章节，在“03 正文纸面”填写生成要求，点击“生成本节”；逐节完成。
7. **编辑与复核**：在段落中修改内容，点击“保存新版本”；可使用划词改写、批注、修订模式。
8. **审校**：点击顶部“一键发起审校”，在审校页逐条处置问题。
9. **套红定稿**：点击顶部“套红排版”，填写发文字号、主送机关等要素，生成定稿稿，在线编辑或下载 DOCX。
10. **提交**：点击“提交检查”（OA 发起的任务显示“提交 OA”），全部检查通过后提交。

## 4. 智能写作

### 4.1 新建写作任务

| 字段 | 说明 |
|---|---|
| 任务名称 | 如“关于申请专项建设资金的请示” |
| 文种 | 请示、报告、通知、函、纪要、通报等；文种决定提纲结构、行文方向和默认输出模板 |
| 密级 | 公开、内部、秘密、机密，决定可用模型和数据范围 |
| 写作主题 | 公文要解决的核心事项 |
| 写作目的 | 行文对象、预期结果和关键要求，写得越具体，生成质量越高 |
| 最少 / 最多字数 | 正文篇幅区间 |

任务按以下状态推进，页面顶部会显示当前所处阶段：

**草稿 → 材料准备 → 提纲生成 → 正文生成 → 审校中 → 已完成**

### 4.2 任务简报与智能参谋

选中任务后，页面显示任务简报（写作目的、篇幅区间、外部知识范围），并提供：

- **智能推荐文种**：综合写作目的、行文关系与材料内容，给出可追溯的文种及结构建议。
- **生成写作提纲**：按文种配置直接生成提纲（也可在工作区中生成）。

### 4.3 写作规划台

- **写作思路**：点击“生成写作思路”，得到文章主旨、核心观点、行文顺序、必须表达、材料缺口和风险提示。可直接修改，确认后点击“确认并锁定本版思路”。
- **标题候选**：生成多个标题供选择。
- **依据问答**：围绕任务和有权限的知识提问（如“材料中对资金测算有哪些明确要求？”），点击“检索并回答”；回答附来源，可点击“确认后插入正文”。

## 5. 正文协同工作区

工作区分为三栏：**01 材料依据**、**02 写作提纲**、**03 正文纸面**。顶部显示材料数、提纲状态、正文版本和 AI 参与比例，并提供版本记录、提交检查、一键发起审校、套红排版、导出等操作。

### 5.1 材料依据

点击“＋”加入材料，两种方式：

- **上传文件**：DOCX、PDF、TXT，单个不超过 20MB，系统提取文本并记录文件指纹。
- **录入片段**：填写材料名称和经核准的材料片段。

每份材料需设置：

| 属性 | 选项 |
|---|---|
| 来源 | 上传、知识库、OA |
| 权威级别 | 正式公文、权威资料、内部资料、参考资料 |
| 使用方式 | 全文参考、指定片段、仅作背景 |
| 引用目的 | 事实依据、政策依据、案例参考、表达参考 |

材料准备完成后点击“**固化材料权限快照**”。正文生成只使用权限为“允许”的材料，生成时也会自动固化快照，确保可追溯。

### 5.2 写作提纲

- 点击“生成”（已有提纲时为“新版本”）按文种配置生成提纲。
- 每个章节可修改标题和写作目的，点击“存”保存，“×”删除，“＋ 添加章节”新增。
- 点击“结构检查”核对章节是否符合文种要求。
- 点击“**确认提纲**”锁定当前版本，之后才能生成正文。

### 5.3 生成正文

1. 在提纲栏选中一个章节。
2. 在正文栏上方的输入框填写生成要求（如“突出事实依据，避免空泛表述”）。
3. 点击“生成本节”，正文以流式方式实时显示，完成后形成新版本。

> 生成的段落标记为“AI生成”，须人工复核。网络中断不会重复生成，系统会自动恢复已生成的内容。

### 5.4 编辑段落

点击段落即可编辑，编辑时出现格式工具栏：

| 按钮 | 功能 |
|---|---|
| B / I / U | 加粗、倾斜、下划线 |
| 1. / • | 编号列表、项目符号列表 |
| 插入表格、+行、+列、−行、−列、删表格 | 表格操作（表格只能放在段落顶层，不能放在列表或表格内） |
| 改写 / 润色 / 扩写 / 缩写 | 划词改写，见 5.6 |
| ↶ / ↷ | 撤销、重做 |

编辑完成后点击段落下方的“**保存新版本**”。每次保存都会形成不可变的新版本。

- **字体、字号、对齐方式**由输出模板统一控制，编辑器中不提供，以保证全单位版式一致。
- 从 Word 粘贴的标题、图片、链接会被转为普通段落或去除。

**多人编辑**：

- 开始编辑某段落时，系统自动为你保留该段落 5 分钟编辑权，并在编辑期间自动续期。其他人此时看到“他人编辑中”，只能查看。
- 如果你保存时该段落已被他人修改，系统会显示“段落已被他人修改”对比窗口，可选择“用我的修改覆盖”或“放弃我的修改”，系统不会自动合并。

**锁定段落**：点击段落下方“锁定”，段落不能被任何人修改或 AI 改写；需要修改时点击“解锁”。

### 5.5 内容来源标识

每个段落左上角显示来源标签：

| 标签 | 颜色 | 含义 |
|---|---|---|
| AI生成 / AI改写 / AI推荐 | 蓝色 | AI 生成或参与修改的内容 |
| 引用原文 | 绿色 | 直接引用材料原文 |
| 人工录入 | 灰色 | 人工编写或修改的内容 |

顶部“AI 参与”显示 AI 内容占比。勾选“导出附 AI 说明”后，导出文件末尾会追加“AI 辅助生成说明”。

### 5.6 划词改写

1. 在同一段落内选中文字（不超过 1000 字，不能跨段落或表格单元格）。
2. 在工具栏点击“改写”“润色”“扩写”或“缩写”。
3. 对比窗口并排显示原文和最多 3 个不同风格的候选（规范庄重、简洁凝练、具体充实），删除的文字以红色划线、新增的文字以绿色下划线标出。可切换方式、填写补充要求后点击“重新生成”。
4. 点击“采用此候选”替换选中文字，再点击“保存新版本”生效。

> 采用 AI 候选后，该段落会标记为“AI改写”。系统会核验候选确实是为该段落生成的，粘贴其他来源的 AI 内容不能绕过标识。

### 5.7 批注

1. 在段落中选中要批注的文字（不选则针对整段）。
2. 点击段落下方“批注”，选择类型（意见 / 批注），填写内容后点击“添加批注”。
3. 批注显示在段落下方，点击引用文字可在正文中定位；处理后点击“解决”。

- 段落保存出新版本后，批注仍跟随该段落。
- 锁定的段落也可以批注。
- 顶部勾选“显示已处理的批注和修订”可查看已解决的批注；原段落被删除的批注集中显示在正文末尾。

### 5.8 修订模式

适用于核稿人员提出修改意见、由起草人决定是否接受的场景。

1. 勾选页面顶部“**修订模式**”（只影响你自己的保存方式，按任务记在本机浏览器）。
2. 修改段落后，段落下方按钮变为“**提交修订**”，提交后正文不变。
3. 修订显示在段落下方：删除的文字红色划线，新增的文字绿色下划线；只改格式的修订显示“仅调整格式”。顶部显示“待处理修订”数量。
4. 起草人或核稿人逐条点击“**接受**”（形成新版本）或“**拒绝**”。

- 同一段落有多条修订时，接受其中一条后，其他修订因原文已变化而标记“已过期”，只能拒绝，避免覆盖。
- 修订中采用了 AI 候选的，显示“含 AI 改写”，接受后段落标记为“AI改写”。

### 5.9 版本记录

点击顶部“版本记录”查看所有版本：

- **恢复**：以历史版本内容生成一个新版本，当前内容仍保留在历史中。
- **保护**：受保护的版本不会被保留策略清理。
- **保留策略**：AI 生成版本保留 30 天、每篇最多 50 个，到期标记 7 天后清理正文；人工提交、提纲确认、审校前后的版本永久保留。

### 5.10 导出

- **导出 DOCX**：保留加粗、列表、表格，AI 参与的段落附来源批注。
- **PDF**：按文字输出，正式版式以 DOCX 或套红定稿稿为准。
- 正式发文请使用“套红排版”生成的定稿稿，见第 6 章。

### 5.11 提交

点击“提交检查”（OA 发起的任务为“提交 OA”），系统按单位配置的提交门禁逐项检查，全部通过后才能提交。提交的版本自动受保护；如配置了“由指定角色确认提交”，需相应角色确认。

## 6. 套红排版与定稿

### 6.1 生成定稿稿

1. 在正文工作区顶部点击“**套红排版**”。
2. 选择输出模板（默认“自动”：依次使用任务的模板、文种的默认模板，都没有时使用**内置标准版式（GB/T 9704—2012）**）。
3. 填写版式要素：

| 要素 | 示例 / 说明 |
|---|---|
| 发文机关标志 | 示范市人民政府文件 |
| 发文字号 | 示政〔2026〕18号（使用六角括号〔〕） |
| 签发人 | 上行文（请示、报告）必填 |
| 主送机关 | 省人民政府： |
| 结束语 | 以上请示，妥否，请批示。 |
| 附件说明 | 1. 项目建设方案 |
| 成文日期 | 默认当天，使用阿拉伯数字，如 2026年10月23日 |
| 抄送机关 | 不填则不显示抄送行 |
| 印发机关 / 印发日期 | 示范市人民政府办公室 / 默认当天 |

4. 点击“生成定稿稿”。标题取自文稿；正文逐段排入模板正文位置，保留加粗、列表和表格。

### 6.2 格式检查

生成后自动执行格式检查，与模板比对页面、边距、字体字号、行距缩进，并检查发文字号括号、签发人、版记、成文日期写法等公文要素。

- 显示“格式检查通过”即符合要求。
- 有问题时逐条列出风险等级（严重 / 重要 / 一般）、应为值和实际值，修改后点击“重新套红”。

### 6.3 在线编辑与下载

- **在线编辑**（启用 ONLYOFFICE 时为主操作）：在浏览器中打开定稿稿微调版式，关闭编辑器后约 10 秒自动保存为新的定稿稿，窗口中会提示“在线编辑已保存为新的定稿稿”。
- **下载定稿 DOCX**：下载最新定稿稿，可用 WPS 或 Word 打开。

> **注意**：正文修改后，旧定稿稿会提示“正文已更新，请重新套红”，此时不能在线编辑，需先点击“重新套红”。
>
> 在线编辑中修改的是定稿稿文件，不会回写正文段落；正文内容的修改请在正文工作区完成后重新套红。

## 7. 智能审校

### 7.1 发起审校

- 从正文工作区点击“一键发起审校”，或在“智能审校”页选择已生成文稿和审校方案后发起。
- 内置四种审校方案：

| 方案 | 适用场景 | 审校层级 |
|---|---|---|
| 快速校对 | 日常材料 | L1、L2 |
| 公文规范审校（默认） | 正式公文拟稿 | L1—L4 |
| 深度内容审校 | 领导讲话、报告 | L1—L6 |
| 内容安全审校 | 对外发布材料 | L1—L7 |

审校层级：L1 基础文字、L2 规范用语、L3 公文规则、L4 格式版式、L5 事实与数据、L6 逻辑与语义、L7 政务内容安全。

### 7.2 处置问题

审校结果按风险、层级和规则依据逐项列出，并给出质量评分。每个问题可：

| 操作 | 说明 |
|---|---|
| 采纳 | 按建议自动修改正文，形成新版本（尽量保留原格式） |
| 采纳同组 | 一次采纳同类合并的问题 |
| 忽略 | 不修改；**严重问题必须填写说明才能忽略** |
| 已修改 | 已人工修改完成 |
| 转人工 | 交由专人判断 |

- **批量采纳**、**批量忽略低风险**（仅限“一般”和“提示”问题）可提高效率。
- L5—L7（事实数据、逻辑、内容安全）问题**不允许自动采纳**，须人工修改后标记“已修改”。
- 标记“模型提出”的问题来自 AI 辅助判断，须人工确认。
- 修改后可点击“重新审校”；可“导出 PDF 报告”或“导出 DOCX 报告”。

## 8. 知识与依据

- **知识库**：点击“＋ 新建”创建知识库（代码、名称、分类、权限范围）。
- **上传文档**：支持 TXT、Markdown、CSV、DOCX 及可提取文本的 PDF；设置文档标题、权威等级和数据权限，上传后点击“开始解析”，状态变为“可检索”后即可使用。
- **检索依据**：在顶部搜索框检索政策、制度、历史公文，结果附出处。检索按你的数据权限过滤。

## 9. 规则与词库（管理员）

### 9.1 审校规则

1. 点击“＋ 新建”，填写规则代码、名称、分类、风险等级、检测方式（词项匹配 / 正则表达式）、适用文种、规则表达式（格式：`错误表达=>建议表达`）和规则依据。
2. 在“命中测试”中粘贴测试文本，点击“运行测试”（发布前必须通过）。
3. 点击“提交审核”，审核人点击“批准并发布”。

规则生命周期：**草稿 → 测试 → 审核 → 生效**，可随时“停用规则”。

### 9.2 标准词库

- 创建词库后可“新增词条”（待规范词语、标准形式、别名、类别 / 风险、来源依据），或“导入 CSV”（UTF-8 编码）。
- 词库保存后在下一次审校时即时生效。

## 10. 输出模板中心（管理员）

输出模板是单位正式公文的 DOCX 版式（版心、字体、版头、版记等），套红排版和 L4 格式审校都以它为标准。

1. 在 Word / WPS 中制作模板，在需要填充的位置写入占位符（见附录 14.2），正文位置单独一段写 `{content}`。
2. 点击“上传 DOCX 模板”，填写模板代码、名称、适用文种、行文方向，勾选是否包含红色版头、版记区域。
3. 系统自动做安全检查（拦截宏、OLE、外部链接）并解析占位符。
4. 点击“模拟填充并下载”检查效果。
5. 点击“发布生效”。同一文种的生效模板会被自动用于套红排版。

> 未发布模板的文种使用内置标准版式。内置版式不含“发文机关署名”，建议各单位上传本单位正式模板。

## 11. 任务与运行中心

文档解析、OA 回调等耗时操作在后台运行，可在此查看：

- 按“运行中 / 已完成 / 需处理”筛选，查看创建、开始、完成时间和重试次数。
- 选中任务查看“执行轨迹”。
- 失败的任务可“人工补偿重试”，未完成的任务可“取消任务”。
- “发起健康检查”用于确认后台任务机制正常。

## 12. 模型与配置治理（管理员）

| 模块 | 说明 |
|---|---|
| 模型端点与数据边界 | 登记模型路由：适用场景、最高数据级别、HTTPS 端点（须在服务端白名单内）、密钥环境变量名（不在系统中保存密钥）、上下文与每日额度 |
| 提示词模板版本库 | 按版本固化完整提示词；草稿 → 测试（发现未解析变量）→ 送审 → 发布后才参与路由 |

| 全链路审计台账 | 查询登录访问、内容操作、模型调用、导出下载、规则配置和安全事件记录 |

所有配置变更都经过测试、审核、发布，并记入审计台账。

## 13. 常见问题

**Q1：点击“创建任务”等按钮没反应，或提示“Invalid CORS request”。**
用 IP 地址或新域名访问时，需要管理员把该访问地址加入后端允许来源（`PLATFORM_ALLOWED_ORIGINS`）。

**Q2：段落显示“他人编辑中”，无法修改。**
其他人正在编辑该段落。对方保存或离开后最多 5 分钟自动释放。

**Q3：保存时提示“段落已被他人修改”。**
在对比窗口中比对你的修改和最新版本，选择覆盖或放弃。

**Q4：修订显示“已过期”。**
提出修订后原文已被修改，该修订不能再接受。请拒绝后基于最新内容重新提出。

**Q5：划词改写按钮是灰色的。**
需要先在同一段落内选中文字，且不超过 1000 字；跨段落、跨表格单元格的选择不能改写。

**Q6：划词改写只有一个候选，或提示没有得到不同的候选。**
未配置模型时系统使用规则引擎，候选较少。可换一种方式或补充要求后重新生成；配置模型后候选更丰富。

**Q7：段落被标为“AI改写”，但我只是做了少量修改。**
只要段落中采用了 AI 候选，整段即标记为 AI 改写，这是为确保 AI 内容如实标识。

**Q8：套红窗口提示“正文已更新，请重新套红”。**
定稿稿基于旧版本正文生成，请点击“重新套红”。

**Q9：看不到“在线编辑”按钮。**
单位未启用 ONLYOFFICE 在线编辑（或正在维护），可下载 DOCX 用 WPS / Word 编辑。

**Q10：在线编辑中字体与正式公文不一致。**
文档服务器尚未安装授权的公文字体，编辑器使用替代字体显示，版式以下载的 DOCX 为准。

**Q11：在线编辑关闭后没有看到新的定稿稿。**
文档服务器在所有人关闭编辑器后约 10 秒保存。未做修改时不会生成新稿；稍后重新打开“套红排版”窗口即可看到最新结果。

**Q12：审校问题无法忽略。**
严重问题须填写说明才能忽略；批量忽略只适用于“一般”和“提示”级问题。

**Q13：审校问题无法自动采纳。**
L5—L7 问题以及没有修改建议的问题须人工修改，修改后标记“已修改”。

### 14.2 输出模板占位符

| 占位符 | 含义 |
|---|---|
| `{title}` | 标题（必填） |
| `{content}` 或 `{#sections}{paragraph}{/sections}` | 正文（必填，建议独占一段） |
| `{sender}` | 发文机关标志 |
| `{doc_number}` | 发文字号 |
| `{signer}` | 签发人 |
| `{recipient}` | 主送机关 |
| `{closing}` | 结束语 |
| `{attachment_desc}` | 附件说明 |
| `{date}` | 成文日期 |
| `{copy_to}` | 抄送机关 |
| `{issue_unit}` | 印发机关 |
| `{issue_date}` | 印发日期 |
| `{#has_attachment}…{/has_attachment}` | 有附件说明时才显示的内容 |
| `{#has_copy_to}…{/has_copy_to}` | 有抄送机关时才显示的内容 |
| `{#has_signer}…{/has_signer}` | 有签发人时才显示的内容 |

### 14.3 术语

| 术语 | 说明 |
|---|---|
| 材料权限快照 | 生成正文时所用材料及其权限的固化记录，保证可追溯 |
| 编辑租约 | 编辑段落时自动获得的 5 分钟编辑权，防止多人同时覆盖 |
| 修订 | 修订模式下提交、待接受的段落修改 |
| 定稿稿 | 套红排版生成或在线编辑保存的正式公文 DOCX |
| 内置标准版式 | 按 GB/T 9704—2012 生成的通用公文版式，文种无已发布模板时使用 |
| L1—L7 | 审校层级，从基础文字到政务内容安全 |
