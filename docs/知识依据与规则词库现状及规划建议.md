# 知识依据与规则词库：现状及规划建议

更新时间：2026-11-02。详细产品边界与落地清单见《知识依据资源与正文使用调整方案.md》。

## 1. 三类能力分别做什么

| 能力 | 定位 | 数据范围 |
|------|------|----------|
| 规则与词库 | 易错词、规范词等可审校命中的词条 | 租户级 |
| 知识与依据 | 政策、制度、历史公文等可检索知识源；经人工选用后可进入本节生成 | 租户级（含公开数据包） |
| 材料依据 | 本次写作任务可用材料及权限快照；分通篇与本节 | 任务级 |

三者不应混用：

- **材料依据**约束「这篇文稿允许引用什么」
- **知识库**提供「单位共享、可检索的依据」；须选用后才进入生成
- **规则词库**服务「审校时按词条纠错/规范」；其中的「法定公文文种」词条不等于写作文种配置

另：**数据字典**只维护界面下拉枚举，不替代文种配置或词库。

## 2. 当前是否已接入生文与审稿

### 2.1 规则与词库

- **生文**：未使用。
- **审稿**：已接入。
- **管理入口**：规则中心「规则与词库」；审校侧可将问题「加入词库」。

### 2.2 知识与依据

- **生文（段落生成）**：已接入**人工选用**路径。本节生成读取该节点已选用知识片段；不自动全库注入。
- **生文（智能问答）**：筹划页仍可检索知识库切片并汇总原文片段。
- **审稿**：未使用知识库检索。
- **公开数据**：安装后进入知识库；经核验与选用后可参与本节生成。
- **资源字段**：写作用途、入库完整性、内容核验、效力字段及发布机关/文号/适用范围等已入库；选用列表隐藏未核验与来源索引等不可用项。

### 2.3 材料依据

- **生文**：已接入。`prepareGenerationContext(taskId, nodeId)` 注入通篇材料 + 匹配本节的材料。
- **分栏**：正文工作区「通篇材料」「本节材料」；上传 / 知识库 / OA 三源均可。
- **字段**：权威级别、使用方式、引用目的为清单标签；使用方式与引用目的**不写入**生成提示词。
- **审稿**：不作为规则引擎输入。

## 3. 入口现状

| 入口 | 状态 |
|------|------|
| 筹划页依据问答 | 保留 |
| 正文工作区查找依据 / 本节选用 | 已提供 |
| 通篇 / 本节材料分栏 | 已提供 |
| 知识条目并入左侧材料列表 | **不做**；知识走选用清单 |

## 4. 规划判断（已执行）

正文侧补齐检索与选用后，知识库可直接服务写稿。后续重点转为：

1. 引用核对与「已引用」升级闭环。
2. 失效、替代、版本变化的审校提示（阶段 4）。
3. 筹划问答与正文选用清单体验统一。

## 5. 能力分工（现行）

| 能力 | 职责 | 入口 |
|------|------|------|
| 通篇 / 本节材料 | 本任务专用；生成按范围注入 | 正文工作区材料栏 |
| 知识选用 | 跨任务共享依据；显式选用后进入本节生成 | 正文「查找依据」；筹划问答保留 |
| 规则词库 | 审校命中与规范纠错 | 规则中心 + 审校加入词库 |
| 文种配置 | 提纲结构与生成约束 | 模型治理 → 文种配置 |
| 数据字典 | 界面枚举 | 侧栏「数据字典」 |

## 6. 一句话摘要

- **规则词库**：审稿用，不服务生文；与写作文种配置无关。
- **知识依据**：筹划问答 + 正文人工选用；选用后进入本节生成，不自动全库注入。
- **材料依据**：通篇 / 本节分栏，仍是生文主链路材料来源。
- **数据字典 / 文种配置 / 词库**：三套配置，边界分离。
