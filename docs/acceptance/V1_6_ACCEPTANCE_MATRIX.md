## 上线签署前的阻断项

1. 在具备 Docker 的 CI 或验收环境取得 PostgreSQL 16 CLOB 迁移实测、Compose 启动、Trivy 双镜像扫描和 SBOM 产物。
2. 配置真实 OIDC、TLS/WAF、DNS、模型端点、PostgreSQL/Redis/MinIO，并验证角色映射、最小权限和密钥轮换。
3. 冻结准确率测试集，完成来源覆盖率、DOCX 结构识别、错别字/术语精确率、召回率、F1 和确定性严重规则漏报统计。
4. 完成生产等价容量压测、10 万字 DOCX、20 路审校、10 路解析、模型端到端与平台自身开销分拆。
5. 完成备份实际恢复演练、RTO/RPO 证明、监控告警、人工可用性、国产浏览器/WPS 与试点验收。
6. 当前目录不是 Git 工作树，无法生成可信代码提交号、签名制品或可追溯发布标签；正式发布前必须纳入受控版本库并执行审批流水线。
